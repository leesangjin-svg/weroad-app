위로드 앱 상태
—
· 출근 버튼을 누르면 위치 전송이 켜지고 상단 알림에 "출근 중"이 떠요. 화면 꺼도, 네비·사진 찍어도 계속 보내요.
· 퇴근 기록을 저장하면 자동으로 꺼져요.
· 처음엔 위치 권한 "항상 허용", 알림 허용, 배터리 "제한 없음"을 물어요 — 모두 허용해 주세요.
안드로이드 폰이네요 — 위로드 앱을 설치하면 화면을 꺼도 위치가 가요
1. 위로드 앱 내려받기 (weroad.apk)
2. 내려받은 파일 열기 → "출처를 알 수 없는 앱" 허용 → 설치
3. 앱 열고 같은 이름·번호로 로그인 → 출근
위치 앱(Traccar Client) 설정 — 아이폰 · 처음 한 번만
1. 앱 설치: Traccar Client (Play 스토어 · App Store, 무료)
2. 기기 식별자(Device identifier): —
3. 서버 주소(Server URL): —
4. 위치 정확도 높음 · 주기 120초 · 거리 0 · 각도 0
5. 맨 위 서비스 상태 켜기 → 이 화면에서 "마지막 위치 수신"이 몇 분 안으로 뜨면 성공
· 안드로이드: 앱 정보 → 배터리 → 제한 없음 (안 하면 밤에 멈춰요)
· 아이폰: 설정 → Traccar → 위치 → 항상
· 이후엔 앱을 건드릴 필요 없어요. 화면 꺼도, 네비·사진 찍어도 계속 보내요.
